Lesson dashboard

Every lesson and exercise on Plot Lab is here. Pick one on the left and edit it. Test this exercise runs the answer and the starting code through the real checks, so you can see that the answer passes and the starting code does not. Press Save to write data/lessons.json (the old file is copied to data/backups/ first). Press Publish to commit the saved lessons and push them to the live site.

Text boxes take HTML: <p>, <code>, <b>, <pre><code> and links all work. Changing a lesson or exercise id resets the progress students have saved for it, so leave ids alone once students have started.
